🎬 NETFLIX CLONE

🍿 Lights. Camera. Code.

A Netflix-inspired streaming website built with HTML5 and CSS3, recreating the cinematic look and feel of a modern entertainment platform.

🍿 Behind the Screen

Inspired by Netflix's iconic streaming interface, this project recreates a movie-browsing experience with a dark cinematic theme, bold typography, vibrant red accents, and carefully styled content sections.

Built as a hands-on frontend development project to explore web design, layout techniques, and the art of bringing a design to life with code.

✨ The Experience

- 🔴 Cinematic Landing Page — A bold hero section with a dramatic background.
- 🎞️ Trending Now — A horizontal collection of movie and show posters.
- 📺 Reasons to Join — Cards highlighting streaming-platform features.
- ❓ Frequently Asked Questions — A dedicated FAQ section.
- 🌐 Language Selection — English and Hindi options.
- 🎨 Netflix-Inspired Aesthetics — Dark backgrounds, striking red accents, gradients, and hover styling.

🛠️ The Tech Behind It

Technology| Purpose
🌐 HTML5| Structuring the webpage
🎨 CSS3| Styling, layouts, gradients, and transitions
📐 Flexbox & CSS Grid| Organizing page elements
📱 CSS Media Queries| Adapting layouts for smaller screens

📂 What's Inside?

- "index.html" — The structure and content of the website.
- "style.css" — The visual styling and layout.
- "assests/" — Background images, the logo, and movie poster images.

🚀 Run It Locally

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No additional dependencies are required for this HTML and CSS project.

💡 What I'm Learning

- Writing structured HTML.
- Styling web pages with CSS.
- Creating layouts with Flexbox and Grid.
- Working with images, backgrounds, and overlays.
- Improving the visual presentation of websites.
